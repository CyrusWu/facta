# Methodology — 版本化规则

这是本产品的**本体**：数据人人有，这套判断标准独一份。

## 结构

- `vN/universal-gates.md` — 通用闸门与打分（对所有项目生效）
- `vN/failure-modes.md` — 失败模式库（签名/检测/实例），新项目先过匹配
- `vN/tracks/*.md` — 每赛道定制判断标准（「深」的主战场），每份对应一个引擎模块 + fixtures

## 铁规

1. **文档是权威，代码是实现。** 改判断规则 = 先改文档、升版本，再改代码、加 fixture；`npm test` 不过不许合。
2. **版本锁定**：引擎版本号 ↔ 方法论版本号一一对应；每份发布物戳 `methodology_version`。
3. **变更留痕**：版本变更必须写明——改了什么、为什么、哪些项目的评级因此变动。
4. **历史不可篡改**：`data/history.jsonl` 是审计轨，任何历史评级可答「当时按哪版方法、哪天数据」。
5. **判断永远人工署名**：方法论约束判断，不代替判断；工具只举旗。
