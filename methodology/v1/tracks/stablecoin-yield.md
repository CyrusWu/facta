# 赛道标准：稳定币与收益 v1-draft

> 地图判词：**价值捕获重灾区里的重灾区——叫得最响的给持有人 ≈$0。**

## 1. 钱流本质
存款人给协议钱（铸稳定币/存金库）→ 协议拿抵押品/策略赚收益 → 收益大头付给**生息凭证持有人**（sUSDe/eUSX 类）→ 「收益给存款人 ≠ 价值给 token 持有人」是本赛道第一陷阱。

## 2. 冠军基线
Sky（Smart Burn 真烧全体、~1%、discretionary 且 2026-03 被砍到 surplus 7.5%）。**本赛道没有 immutable 冠军**——这是空缺不是锚点错。挑战者基线：Spark（真回购但进金库）。反面锚：Ethena（纸面开关）、USUAL（trust 崩）、SLX（免费券）。

## 3. 赛道特有指标
- **Float economics**：不生息部分的供给 × 抵押品收益率 = 隐形收入（Tether/Circle 模型）；它归谁、在哪个法人（SLX：$423M 零息 float 的利息在链下 BVI）。
- **铸赎权限**：permissioned（仅机构 KYC）→ TVL=mint 口径非需求口径，且**散户无套利 → "fully backed" 不构成价格地板**（USX 曾 $0.78）。
- **Peg 史**：脱锚次数/深度/恢复方式（手动注入=红旗）。
- **收益率来源分解**：funding 捕获/RWA 利息/借贷利差各占多少；funding 类在费率压缩期的衰减曲线（Ethena 收入 1y $12.4M → 30d 年化 $0.87M）。
- **PoR/PoS 覆盖范围**：证的是抵押还是业绩？覆不覆盖链下腿？（储备证明 ≠ 业绩证明）。

## 4. 赛道特有闸门
- 收益引擎在链下法人 + token 在链上 → **结构性无费池**,直接按 G1 处理（SLX 教训）。
- 单方改赎回价/规则前科 → trust-gate fail（USUAL 的 USD0++ $1→$0.87）。
- 积分表雇人持有不生息资产（Hold USX=10x vs eUSX=2x 式）→ TVL 质量降级。

## 5. 高发失败模式
#1 假holders口径、#4 月脉冲、#8 免费券、#9 链下费池、#10 纸面开关、#11 删正文、#14 业绩平滑。

## 6. 口径注意
DeFiLlama 对这类协议常记 `Revenue: $0 (yield fully passed to holders)`——那是**适配器口径不是事实**，链下 float 收入它看不见；判词要写「真收入+零通道」而非「零收入」。
