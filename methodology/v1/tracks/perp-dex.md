# 赛道标准：永续/衍生品 DEX v1-draft

## 1. 钱流本质
交易者付 taker/清算费 → 分给 LP/保险基金/协议 → 唯一大额+自动+被动可得的只有 Hyperliquid。费是真需求但**强周期**：回购=交易量的函数，熊市买盘与费同时蒸发（顺周期自毁）。

## 2. 冠军基线
HYPE：~97% 费自动买回、realized ~3.5-4%（在缩）、governance-set-auto（比例可改，已改三次）。反面锚：edgeX（补贴幻觉）、dYdX（买入并质押）、ASTER（wash 费基）。

## 3. 赛道特有指标
- **量的真伪**：wash 检查（与 CEX 逐笔对照/数据商下架史/换手比）先于一切——费基假则全假。
- **回购与量的弹性**：季度回购序列（HYPE 三连 -40%）；牛熊两态下的 yield 区间，不报单点。
- **分配比例的治理可改性**：改过几次、谁能改。
- **解锁 vs 回购净额**：本赛道新生多带大解锁（LIT 2026-12 起 75%）。
- **口径**：「净利润回购」这种自定义口径要求对账（edgeX 的"净利润"不透明=红旗）。

## 4. 赛道特有闸门
- 数据商因疑似 wash 下架 → trust-gate fail（ASTER）。
- 回购 > 协议收入 → G7 补贴幻觉封顶。
- 买回后质押/进国库而非销毁分红 → G5/G6 封顶。

## 5. 高发失败模式
#2 补贴幻觉、#6 买入并质押、#7 净稀释、#15 wash 费基。

## 6. 口径注意
HyperCore 类自建链不在 Blockscout 索引 → 链上核验走 DeFiLlama 派生 + 社区面板（ASXN 等），标注核验层级。
