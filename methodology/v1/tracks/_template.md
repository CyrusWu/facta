# 赛道判断标准模板 vX-draft

> 每赛道一份。文档 ↔ 引擎模块 ↔ fixtures 三位一体。

## 1. 赛道钱流本质（一句话 + 图）
谁付钱、付什么钱、经过哪些节点、到谁手里。大多数项目在哪一步把持有人甩出去。

## 2. 冠军基线（锚点）
本赛道价值捕获做得最好的是谁、什么水平（yield/机制/规模）——所有新项目对着它量位置。

## 3. 赛道特有指标
通用指标之外，本赛道必须看的 3-6 个数（及其数据源与口径陷阱）。

## 4. 赛道特有闸门/红旗
在通用 G1-G8 之上追加的一票否决或封顶条件。

## 5. 赛道特有失败模式
引用 failure-modes.md 中高发条目 + 本赛道独有变体。

## 6. 数据口径注意
本赛道在 DeFiLlama/CoinGecko 上的已知坑。
